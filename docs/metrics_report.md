> ## Read this first
>
> **Every clip behind these numbers is synthetic**, generated by
> `src/synthetic.py` from a 2D forward-kinematic stick figure. The
> figures below therefore measure whether the *logic* works - angle
> maths, rep state machine, threshold rules, unknown-rejection,
> latency - and say nothing about real-world accuracy. In
> particular the synthetic classes are far more separable than real
> recordings, so the classification accuracy is an upper bound and
> should be read as "no bug", not as "99% accurate".
>
> They also exclude the two largest real-world error sources:
> BlazePose landmark error under occlusion/motion blur, and genuine
> out-of-plane movement.
>
> To get real numbers: record clips with
> `python -m src.main --record squat --exercise squat`, annotate
> `expected_reps` / `expected_codes`, retrain, and re-run this script.
